Descrizione:
Questa repository contiene una serie di esercizi di programmazione C++ sviluppati nell’ambito del Laboratorio di Calcolo I. Gli esercizi sono numerati e ciascun file contiene una soluzione specifica per problemi assegnati nel corso.

Struttura della repository:
La repository include diversi file .cpp, ciascuno rappresentante un esercizio numerato. Di seguito, una panoramica della struttura:

	-	Esercizio1.cpp - Soluzione per l’esercizio 1
	-	Esercizio2.cpp - Soluzione per l’esercizio 2
		…
	-	Esercizio20.cpp - Soluzione per l’esercizio 20
	-	File extra come Esercizio3TS.cpp e Esercizio5TS.cpp rappresentano varianti
 	-	La relazione in formato .pdf consultabile
	-	Altri file .txt utili. 

Ogni file contiene la risoluzione di un esercizio in C++, utile per comprendere vari concetti fondamentali nell'ambito della Fisica Computazionale. Il comando di compilazione è indicatoa  inizio file.

Requisiti:
	-	Linguaggio: C++
	-	Compilatore: G++ (o un altro compilatore compatibile con C++)
